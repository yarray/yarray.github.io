## Products {#products}

### Designed and led the development of the cloud-native, AI-native high-performance geographic information platform HiGIS 2.0; released the DeepGlobe software series, one architecture spanning embedded standalone devices to clusters

- **Unified API standard**: standard-first, one standard with multiple implementations, supporting partial replacement and free composition; a layered resource model of L0 basic spatio-temporal elements plus L1 classic GIS capabilities, where any object can bind spatio-temporal attributes and attached resources, uniformly representing vectors, rasters, trajectories, street views, 3D and other data
- **Cloud-native architecture**: self-developed high-performance Rust kernel with a microservice architecture; the lightweight server runs in under 100 MB of memory and the whole system runs smoothly in 2 GB; K8s microservices composed on demand with elastic scaling
- **AI-native architecture**: shared intelligent infrastructure for end users and secondary developers — the DeepGlobe SDK component library, agent skill packs, CLI/MCP shared by humans and AI, and a series of intelligent algorithms
- **Development and operations infrastructure**: continuously compiled and published design documents with automated conformance testing; multi-level functional and performance test coverage combining intelligent generation and intelligent regression; automatic registration and publishing interfaces for third-party spatial analysis tools; a multi-person, multi-agent collaborative development management workflow
- **Organized the team to develop and release the self-reliant software product HiGIS DeepGlobe**: covering backend services, web and mobile clients; incremental services such as data, computation and visualization intelligence and scene compilation; adapted to Phytium/Loongson CPUs and the Kylin operating system, with mobile engines on both Android and HarmonyOS
- Supported 5 major engineering programs; serving 160+ organizations and 90,000+ users

### Developed (or supervised the development of) a family of high-performance / intelligent geospatial analysis algorithms

- Vector data I/O library, 6-10x faster than GDAL
- Parallel overlay analysis and other fundamental algorithms, 5x+ faster than ArcGIS

- Supervised: 3DGS-based 3D reconstruction, 3D/vector/imagery semantic matching, radar 3D detection capability analysis, road-network-free path planning, etc.
